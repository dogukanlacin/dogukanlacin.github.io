# Doğukan'ın Notları

Noir / editoryal tasarımlı, boş içerik arşiviyle başlayan kişisel yazı sitesi.

## GitHub Pages ile yayımlama
1. ZIP içindeki dosyaları çıkarın.
2. Tüm dosya ve klasörleri `dogukanlacin.github.io` deposunun ana dizinine yükleyin.
3. GitHub'da **Settings → Pages** bölümüne gidin.
4. **Deploy from a branch** seçin; Branch: `main`, Folder: `/(root)` olarak ayarlayın ve **Save**'e basın.
5. Birkaç dakika sonra `https://dogukanlacin.github.io` adresini kontrol edin.

Yazı eklemek istediğinizde ayrı bir yazı sayfası ve arşiv bağlantısı oluşturulabilir. Şu an pakette hiçbir yazı içeriği yoktur.
